# loanDepot Visual Branding for Generated Docs

## Primary Accent Color (Purple)
- Hex: #6B2D8F (deep purple used for accents, headers, links, borders, badges)
- Use for:
  - Logo backgrounds / icons
  - Accent borders and lines (callouts, table headers if styled)
  - Hover states on links and nav
  - Badge / pill backgrounds (light tint #F3E8FF with text #6B2D8F)
  - PDF accent lines / highlights

## Typography
- Body: Inter or system sans-serif (clean, readable)
- Display / Headings: Space Grotesk or similar geometric sans (modern, friendly)
- Keep weights: 400/500/600 for hierarchy
- Avoid heavy serif or overly decorative fonts

## Overall Visual Principles (from site inspection)
- Clean, modern, trustworthy design
- High contrast dark text on light backgrounds
- Generous whitespace
- Purple accents on white/light gray backgrounds for premium feel
- Consistent rounded corners on cards / badges

Apply this consistently when generating or updating HTML/PDF artifacts so all docs feel on-brand with loanDepot.
