# Open Group Technical Publications Style Guide - Key Excerpts for Document Structure

Source: https://pubs.opengroup.org/handbooks/technical-publications-styleguide/index.html

## Document Structure (Chapter 2)

### Front Matter (adapt for user guides)
- Title Page (or prominent title)
- Copyright / version info
- Contents (auto or manual TOC)
- Preface:
  - Introduction (brief about the doc purpose)
  - This Document (audience, overview of structure, typographical conventions, how to use)
  - Intended audience & prerequisite knowledge
- Referenced documents (if any)
- Acknowledgements (optional)

### Body Text
- Chapters (each covers one main topic)
  - Use numbered sections (level 2 headings) and subsections (level 3)
  - Avoid 4th level and deeper
- For each chapter where appropriate:
  - Objective / purpose
  - Overview
- Appendices for reference material that would interrupt flow
- Glossary (brief definitions)
- Index (for longer docs)

Rules:
- Chapters/sections: have more than one subsection if subdividing.
- Use lists, tables, figures, notes, cross-references.
- Keep consistent.

## Writing Style Highlights (Chapter 3)

### General
- Short sentences (preferably <25 words).
- Plain language, unambiguous. No contractions in formal but can relax for friendly user docs.
- Consistent terminology. Define on first use, add to glossary.
- Active voice, present tense preferred.
- No jargon, idioms, slang, humor that doesn't translate.
- Use "you" for direct address in user guides.
- American English spelling.
- Capitalize specific titles, use sentence case appropriately.

### Lists
- Introduce with complete lead-in phrase + colon.
- Parallel construction.
- Capitalize first word of each item.
- No end punctuation on list items unless full sentences.
- Use numbered for sequences/procedures, bullets for choices/groups, definition lists for term + desc.

### Tables
- Introduce with sentence + colon.
- Capitalize first word in cells.
- Keep simple.

### Titles / Headings
- Title case for main: capitalize first/last, nouns, verbs, etc. Avoid starting with article.
- Descriptive.
- Gerund for procedures (e.g., "Understanding Your Metrics").

### Other
- Examples: meaningful, illustrate usage.
- Cross-refs precise.
- Footnotes sparingly.
- Graphics: clear captions.
- Numbers: numerals mostly.
- Define abbreviations first time (Full (ABBR)).

Use for this skill: Make docs scannable, consistent, professional yet approachable. Limit nesting. Strong glossary and examples.
